# Прототип дашборда «Накопленная выручка месяца»

Локальный HTML-прототип для согласования структуры таблиц и графиков.

## Сборка

1. Выгрузить лист `raw_data_income` каждого месяца в CSV: `YYYY-MM.csv` в одну папку.
2. Собрать данные и HTML:

```bash
python3 build_data.py <папка_с_csv> data.js --as-of 2026-11-12 --today 2026-11-13
python3 build_html.py data.js dashboard_prototype.html
```

Результат - один файл `dashboard_prototype.html`, открывается в браузере без интернета.

## Правила расчёта

- Выручка - столбец H «Выручка (рубли)» как есть; филиал - столбец K «Школа».
- Срез - вчера (D-1); сегодняшний день не участвует в расчётах.
- Сравнение по числу месяца; прогноз = итог базы × (факт 1-D / база 1-D).
- Собственная сеть: Москва-Барабны-1, Санкт-Петербург -Барабны-1, Казань-Барабны-1, Тюмень-Кидс-2, Владикавказ-Кидс-1.
