# Устройство сайта отчётов

```
site/
  index.php        вход и страницы отчётов (index.php?r=<id>)
  admin.php        настройки: состояние и источники всех отчётов, ключ Google, расписание, пароль, журнал
  cron.php         обновление всех отчётов по расписанию (или одного: cron.php debt)
  setup.php        первичная настройка логина и пароля
  health.php       версия кода (ручная проверка после выкладки)
  lib/             общее ядро: настройки, вход, Google Sheets, реестр отчётов
  templates/       общая шапка с меню, страница отчёта, вход
  assets/          общие стили, меню
  reports/
    revenue/       «Накопленная выручка месяца»
    debt/          «Задолженность по роялти»
  data/            на сервере: настройки, ключ, кэш, данные отчётов (не в репозитории)
tests/run.php      автотесты на синтетических данных
.github/workflows/deploy.yml   тесты и выкладка по FTP
```

## Как добавить отчёт

Создать папку `site/reports/<id>/` с файлами:

| Файл | Что внутри |
|---|---|
| `report.php` | функции отчёта и в конце `return [...]` с описанием: `id`, `title`, `group` (раздел меню), `desc`, `order`, `data_var`, `defaults`, `build`, по желанию `admin`, `admin_save`, `css` |
| `controls.php` | фильтры и вкладки отчёта (вставляются в шапку) |
| `view.js` | отрисовка отчёта по данным из `window.<data_var>` |
| `view.css` | стили отчёта (необязательно) |

`build(array $settings, SheetSource $src, string $dir, array &$warnings)` возвращает `['payload' => данные, 'sources' => [...], 'summary' => [подпись => значение]]`.

После этого автоматически:
- в меню появляется новый пункт;
- `cron.php` начинает обновлять отчёт;
- в настройках появляется его раздел.

Отчёты обновляются по возрастанию `order`. Если отчёт использует данные другого (например, задолженность берёт статус школ из выручки), ему нужен больший `order`.
